## 2. 社区 baseline 在其**本体环境**的真实水平（seeds 0–4，脚本 `remote_platform/audit_mattjacobs.py`）

| 运行方式 | mean | 逐种子 |
|---|---|---|
| 原生 `env.step()`（他们的代码） | **1058.8** | [771,1538,403,1451,1131] |
| 我们旧适配器（复刻 step 循环） | 1048.8 | [1050,1114,1091,813,1176] |

- 均值差 −1% → **旧适配器的物理循环在期望意义下是保真的**。
- 但逐种子差 ±300–700：根因是**他们的 env 每个 seed 不可复现**——`reset()` 只用
  `default_rng(seed)` 种了开局随机果，局内出生走全局 `preparticle.rng`（从不重播种）。
  因此任何"单种子分数"（包括我们曾展示的 **1604**）都只是某条随机出生流的幸运样本，
  不代表该 policy 的水平；社区 baseline 的真实水平 ≈ **1050±350（5 种子）**。
- 处置：适配器已改为**原生 `env.step()` + 钩住 `space.step` 逐帧快照**（构造上保真），
  并在 reset 后播种 `preparticle.rng=seed+100000` 使回放可复现（已标注的偏差）。
  重采集 seed0 = **852**（与原生分布一致），观测台 manifest 已更新。

## 3. "我们另一个 agent 有问题" 的诊断结论

| 对象 | 结论 |
|---|---|
| mattjacobs 适配器 | 循环保真（均值 Δ≈−1%）；真问题是**单种子展示误导**（其 env 不可复现）+ 已换原生 step 实现 |
| **AlphaZero（rl/）** | **确为弱环**：同环境 814（200 visits 仅 1004）vs heuristic 1900。搜索 4× 预算仅 +10% → 搜索在运作但**网络饥饿**（仅 ~9k 优化步）+ fast-model 近似。属"欠训练/配置弱"，非崩溃型 bug。建议：不再作为竞争基线展示，或以 DQN 级算力重训 / 从 heuristic 蒸馏 |
| cluster DQN | 实现无误（与其自带 eval 一致）；但**在自己训练环境里仍输给 1 步前瞻 heuristic（1290 vs 1812）** → settle 动力学下价值学习比 1 步真物理前瞻难，仍欠训练；wave2 scale 正确，另建议把 heuristic 当教师（BC 初始化 / DAgger） |

## 4. 对"社区强 baseline"的总判断

- 其本体环境 ≈1050（5 种子）；迁入我们环境仅 672。
- 受控对比下它**不强于**我们的 cluster DQN（1290/1315）与 heuristic（1812）。
- 因此当前最强控制器 = heuristic（settle 环境）；最强 RL policy = cluster DQN；
  "无敌 policy" 的门槛应以 **heuristic 1812/2004** 为靶，而非社区 1050。

- 两个 wave3b policy **均已稳定越过 2000 分门槛并合成西瓜**，mean 显著超过 heuristic 靶线（1596/16种子）。
